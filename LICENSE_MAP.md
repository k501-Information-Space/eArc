# eArc — Object-Level License Map

**Policy:** 2.0 — Neutral Archive  
**Repository role:** `NEUTRAL_DEVELOPMENT_ARCHIVE`  
**Default rights state:** `RIGHTS_OPEN`  
**Authority granted by storage:** `NONE`

eArc is a mixed development archive. No folder-wide MIT or CC BY 4.0 grant
applies to `raw/**`, `archive/**`, `src/**`, `include/**`, `spec/**`,
`semantic_ingest_v1/**`, `test_ingest_20/**`, legacy-named
`canonical/**`, historical state folders or root data. Public presence is
not proof of ownership or permission.

- `LICENSE`: MIT instrument for exact software objects individually listed
  in `RIGHTS_REGISTER.json`.
- `LICENSE-CONTENT`: CC BY 4.0 instrument for exact documentation objects
  individually listed in `RIGHTS_REGISTER.json`.

Initial CC BY 4.0 grants are limited to the new eArc curation, governance,
object schema, navigation, transition and validation documents listed in
the rights register. No existing source code, core, workspace, conversation,
QH256 implementation/validation package, pipeline/runtime release,
publication file, binary, test data or derived output receives a new blanket
grant. No existing software is MIT-licensed solely because it resides in
`src/` or `include/`.

Unregistered objects default to `RIGHTS_OPEN`. `RIGHTS_REVIEWED` is not
itself a licence grant. Valid file-specific/third-party terms take
precedence. This is an administrative map, not legal advice or complete
provenance clearance.
