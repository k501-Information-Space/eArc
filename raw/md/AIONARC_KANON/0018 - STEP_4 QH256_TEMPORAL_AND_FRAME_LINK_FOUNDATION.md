Copy-Paste Block 6:

```bash
find temporal frames links continuity \
-type f \
\( -name "*.md" -o -name "*.json" \) \
-exec sha256sum {} \; \
> hashes/QH256_TEMPORAL_FOUNDATION_SHA256_v1.txt

while read -r hash file; do
  echo "$hash" > "${file}.sha256"
done < hashes/QH256_TEMPORAL_FOUNDATION_SHA256_v1.txt
```
