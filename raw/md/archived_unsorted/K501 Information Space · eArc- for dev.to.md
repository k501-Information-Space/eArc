# K501 Information Space · eArc

We officially opened the new public repository for the K501 Information Space:

[https://github.com/k501-Information-Space/eArc](https://github.com/k501-Information-Space/eArc)

eArc is part of the ongoing K501 Information Space development.

It is not an AI product.  
It is not a chatbot framework.  
It is not an autonomous agent system.

eArc is an append-only information and frame architecture.

The project focuses on:

- deterministic archival structures
    
- canonical frame systems
    
- temporal anchoring
    
- provenance preservation
    
- gateway-oriented navigation
    
- semantic stability
    
- human/machine-readable knowledge structures
    

A central concept inside the repository is:

Gateway.md

Gateway.md acts as a structural orientation layer for both:

- humans
    
- machine systems
    

The goal is not “AI interpretation”.

The goal is:  
clear structure,  
persistent references,  
and observable evolution over time.

The recent repository cleanup showed something important:

The development data itself already contains the structure.

Frames create frames.  
Structure creates structure.  
Knowledge emerges through continuity,  
not through overwrite.
