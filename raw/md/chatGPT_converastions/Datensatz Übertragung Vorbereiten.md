**M1 — Source Registry**
- Zweck: Quellenkatalog (Websites, Archive, Datenbanken, PDFs, APIs, Bücher/Scans als Metadaten)
- Input: Source-Einträge
- Output: `SRC-*` Records (ID, Typ, Region, Trust-Historie, Lizenz/ToS-Hinweis)

- Zweck: Abruf + Einlagerung von Rohmaterial (HTML/PDF/JSON/CSV)
- Output: `RAW-*` Artefakte (unverändert)
- Pflicht: Hash + Timestamp + Retrieval-Kontext (URL, Header, Snapshot-Info)

**M3 — Normalization Layer**
- Zweck: Alles in ein einheitliches Zwischenformat bringen
- Output: `NORM-*` (Text, Tabellen, Metadaten, Sprache, Encoding)
- Regeln: Original bleibt unangetastet; Normalisierung ist nur Ableitung

**M4 — Language & Translation Gate**
- Zweck: Sprachdetektion + optionale Übersetzungsableitung
- Output: `TXT-original`, `TXT-en`, `TXT-de` (je nach Setup)

- Zweck: Doppelte Ereignisse/Claims zusammenführen (ohne Inhalte zu verlieren)

import numpy as np
import wave
from pathlib import Path

SR = 48000
out = Path("/mnt/data/audio_sim2")
out.mkdir(exist_ok=True)

def tone(freq, dur, wave_type="sine", amp=0.25):
    t = np.arange(int(SR*dur)) / SR
    if wave_type == "sine":
        x = np.sin(2*np.pi*freq*t)
    elif wave_type == "square":
        x = np.sign(np.sin(2*np.pi*freq*t))
    else:
        x = np.sin(2*np.pi*freq*t)
    env = np.ones_like(x)
    a = int(0.01*SR); r = int(0.04*SR)
    env[:a] = np.linspace(0,1,a,endpoint=False)
    env[-r:] = np.linspace(1,0,r,endpoint=False)
    return (x*env*amp).astype(np.float32)

def write(name, sig):
    sig = sig/np.max(np.abs(sig))*0.9
    pcm = (sig*32767).astype(np.int16)
    with wave.open(str(out/name), "wb") as f:
        f.setnchannels(1)
        f.setsampwidth(2)
        f.setframerate(SR)
        f.writeframes(pcm.tobytes())
