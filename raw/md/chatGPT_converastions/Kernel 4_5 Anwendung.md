### 0) Grundsatz
**Browser = nur URLs / externe Inhalte.**

## 1) Schichtenmodell (Layer)

### Layer A — **HMI Shell (Host)**
Aufgaben:
- Start/Stop/Reset Buttons
- FPS/Tick Anzeige
- Audio on/off
- Input-Mapping
- Safe-Errors (statt Crash)

Technik:
- Minimaler WebView / Local HTML (offline möglich)

### Layer B — **Renderer**
Zwei Modi (wählbar):
1) **SVG Renderer (DOM-SVG)**  
   - Ideal für UI-Games: Sudoku, Menüs, Karten, Puzzle
2) **Canvas Renderer (optional)**  
   - Für schnelle Arcade-Games (Tetris/Snake) wenn SVG zu schwer wird

**Wichtig:** Renderer ist **klar getrennt** von Navigation.

### Layer C — **Game Core (Pure Logic)**
- Game State (Board, Score, Timer, RNG seed)
- Rules (Kollision, Punkte, Level)
- Update Loop (`tick(dt)`)
- No DOM, No UI — nur Daten

→ Dadurch keine Interpretationsfehler: Logik ist testbar.

### Layer D — **Input**
- Touch/Mouse/Keyboard → Events
- Normalisierung (tap/swipe/drag)
- Übergabe an Game Core (intent-based)

### Layer E — **Audio (Open Source)**
- WebAudio API (Synth/SFX)
- Sound Events aus Game Core (z. B. `SFX_LINE_CLEAR`)
- Kein Audio im Core, nur Signale

### Layer F — **Persistence & Logs**
- Save/Load (JSON)
- Replay (Seed + Inputs)
- Frames/Logs append-only (dein Standard)

---

## 2) Datenfluss (wichtigster Teil)

**Input → Core → Render → Output**

1. User tippt/swiped  
2. Input layer macht daraus „Intent“  
3. Core aktualisiert State  
4. Renderer zeichnet State als SVG  
5. Audio spielt ggf. Event ab  
6. Logger schreibt Frame (optional)

**Keine UI-Logik im Core. Keine Core-Logik im Renderer.**

---

## 3) SVG-Renderer Regeln (damit es stabil bleibt)

### SVG nur als:
- `<svg>` im DOM
- oder `.svg` Datei lokal geöffnet
- oder `data:image/svg+xml;base64,...` (nur wenn nötig)

- URL-Bar Text
- „Suchanfrage“ im Browser

### Touch-Targets
- Jede interaktive Fläche bekommt:
  - `data-hit="cell-3-5"` (oder id)
  - `pointer-events: all`
  - Mindestgröße (Finger): ~44px

- Nur **diff-rendern**:
  - ändere nur Zellen/Layer, nicht das komplette SVG neu erzeugen
- Layering:
  - `background`, `grid`, `pieces`, `hud`, `overlay`
